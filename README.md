# ADC-Input

<img width="842" height="685" alt="image" src="https://github.com/user-attachments/assets/85462bba-2953-432b-adf7-f6ec3543eb70" />

Навчальний проєкт для **ESP32-S3**, присвячений зчитуванню аналогового сигналу з фоторезистора (LDR), перетворенню показів ADC у напругу та порівнянню розрахованої напруги з результатом `analogReadMilliVolts()`.

Проєкт створено в межах **модуля 1.6** — «Вимірювання освітленості за допомогою LDR та ESP32-S3».

## Мета

- Підключити LDR до ESP32-S3 як подільник напруги.
- Зчитувати цифровий код ADC за допомогою `analogRead()`.
- Розраховувати напругу за RAW-кодом.
- Отримувати оцінку напруги за допомогою `analogReadMilliVolts()`.
- Виводити результати в Serial Monitor для подальшого порівняння.

> **Примітка:** схема вимірює напругу, що залежить від освітленості LDR. Вона не вимірює освітленість у люксах без додаткового калібрування та характеристики конкретного фоторезистора.

## Апаратна частина

### Компоненти

- ESP32-S3 DevKitM-1 або сумісна плата ESP32-S3.
- Фоторезистор (LDR).
- Резистор **10 кОм**.
- Макетна плата та з'єднувальні проводи.

### Підключення

LDR і резистор утворюють подільник напруги:

1. Підключіть один вивід LDR до **3.3 V**.
2. Другий вивід LDR підключіть до вузла вимірювання.
3. Підключіть резистор **10 кОм** між вузлом вимірювання та **GND**.
4. Підключіть вузол вимірювання до **GPIO2** (ADC1_CH1 на ESP32-S3).

Схематично:

```text
3.3 V
  |
 LDR
  |
  +---------- GPIO2 (ADC)
  |
 10 kΩ
  |
 GND
```

У цій конфігурації зі зменшенням опору LDR напруга на GPIO2 зазвичай зростає. Переконайтеся, що напруга на вході не перевищує допустимий рівень для плати.

## Як обчислюється напруга

Програма використовує 12-бітний діапазон ADC із максимальним кодом 4095 та задану опорну напругу 3.1 V:

```text
U_calc = (RAW / ADC_MAX) × U_REF
ADC_MAX = 4095
U_REF   = 3.1 V
```

Наприклад, для RAW = 3000:

```text
U_calc = (3000 / 4095) × 3.1 ≈ 2.27 V
```

Це розрахункова оцінка за заданими параметрами, а не гарантовано точне значення напруги на GPIO. Реальна характеристика ADC залежить від конфігурації та калібрування. `analogReadMilliVolts()` повертає результат у мілівольтах із використанням механізмів калібрування, доступних Arduino-ESP32.

## Програмне забезпечення

Проєкт використовує:

- [PlatformIO](https://platformio.org/) як середовище збирання;
- [Arduino framework для ESP32](https://docs.espressif.com/projects/arduino-esp32/en/latest/);
- C++.

Конфігурація плати та середовища міститься у файлі `platformio.ini`.

## Запуск

1. Встановіть Visual Studio Code та розширення PlatformIO IDE.
2. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/y-kondrashov/ADC-Input.git
   cd ADC-Input
   ```

3. Відкрийте проєкт у Visual Studio Code із PlatformIO.
4. Підключіть ESP32-S3 через USB.
5. Зберіть і завантажте програму командами PlatformIO **Build** і **Upload**.
6. Відкрийте **Serial Monitor** зі швидкістю **115200 baud**.

## Поточна поведінка програми

- Перевіряє час і запускає цикл вимірювання приблизно кожні 100 мс.
- Зчитує RAW-код через `analogRead(GPIO2)`.
- Обчислює напругу за формулою вище.
- Отримує напругу в мілівольтах через `analogReadMilliVolts(GPIO2)`.
- Виводить RAW, розраховану напругу та виміряне значення в Serial Monitor.
- Вмикає LED на GPIO17, якщо RAW менший за поріг 2500; інакше вимикає його.

Приклад виводу:

```text
ADC raw value: 2985 | U calculated: 2.26V | Read millivolts: 2535
ADC raw value: 3256 | U calculated: 2.46V | Read millivolts: 2719
```

Фактичні значення залежать від освітлення, конкретного LDR, резистора та характеристик ADC.

## Порівняння результатів

Для порівняння двох оцінок напруги можна обчислити абсолютну різницю:

```text
Difference (mV) = |U_calc × 1000 - U_measured_mV|
```

А відносне відхилення від значення `analogReadMilliVolts()`:

```text
Deviation (%) = Difference (mV) / U_measured_mV × 100%
```

Цей відсоток показує відносну різницю між двома способами оцінювання, а **не абсолютну похибку ADC**. Щоб оцінити похибку відносно фактичної напруги, потрібне незалежне контрольне вимірювання, наприклад мультиметром.
